# Project X

> One platform. One university.

Project X is a unified digital campus platform designed to bring fragmented university systems into one seamless, role-based experience. This website presents the product vision, key workflows, technical architecture, impact, and the team behind the project.

Built for Microsoft Innovate 2026 by Team 257.

## Highlights

- Unified access to academic, administrative, and campus services
- Role-based experiences for students, faculty, and administrators
- AI-powered campus assistant backed by a shared university knowledge base
- Product walkthroughs, architecture, impact, and team sections
- Responsive interface with motion-driven presentation and campus imagery

## Tech Stack

- Next.js 14 with the App Router
- React 18 and TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

## Project Structure

```text
src/app/             Next.js app entry points and global styles
src/components/      Page sections and reusable UI components
public/images/       Product screenshots, logos, and team images
```

## Deployment

This project is configured for deployment on [Vercel](https://vercel.com/). Import the GitHub repository, keep the detected Next.js settings, and deploy. Vercel will use the standard `npm run build` command automatically.
